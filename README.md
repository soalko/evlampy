# Evlampy Messenger (C++/CMake)

`Evlampy` — клиент-серверный мессенджер с шифрованием сообщений.

Текущая версия реализует минимальный MVP-демо-сценарий:
- регистрация и аутентификация пользователей на сервере;
- обмен сообщениями в реальном времени через серверный транспорт;
- шифрование сообщения AES-256-GCM;
- шифрование сеансового AES-ключа RSA-2048 (OpenSSL);
- хранение серверной истории сообщений в памяти процесса.

## Стек и зависимости

- C++17
- CMake >= 3.10
- OpenSSL (Crypto)
- Threads (pthread на Linux/macOS)

## Структура проекта

- `include/` — публичные заголовочные файлы по модулям
  - `chat/`
  - `network/`
  - `encryption/`
  - `patterns/`
- `src/` — исходники модулей
  - `chat/`
  - `network/`
  - `encryption/`
  - `patterns/` 
- `CMakeLists.txt` — конфигурация сборки

## Сборка (out-of-source)

```bash
cmake -S . -B build
cmake --build build
```

## Запуск

```bash
cd build
./target_exec
```

Ожидаемый результат: в консоли появится лог регистрации/входа пользователей и расшифрованное сообщение у получателя.

## Что демонстрирует `target_exec`

1. Создает сервер и двух клиентов (`alice`, `bob`).
2. Регистрирует пользователей и генерирует RSA-пары ключей.
3. Выполняет логин пользователей.
4. Отправляет сообщение от `alice` к `bob` через `SendMessageCommand`.
5. `bob` получает и расшифровывает текст сообщения.
