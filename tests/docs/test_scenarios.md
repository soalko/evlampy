# Тестовые сценарии Evlampy

Ниже перечислены сквозные сценарии, реализованные как отдельные мини-программы в `tests/scenarios/`.

1. `scenario_auth_flow`
   - регистрация пользователя;
   - первый логин;
   - logout;
   - повторный логин тем же профилем.

2. `scenario_direct_message`
   - регистрация и логин двух пользователей;
   - отправка личного сообщения;
   - проверка расшифрованного сообщения в истории получателя.

3. `scenario_group_flow`
   - регистрация и логин двух пользователей;
   - создание группы;
   - отправка группового сообщения;
   - проверка отображения группового сообщения у участника.

4. `scenario_delete_for_all`
   - отправка личного сообщения;
   - удаление сообщения отправителем для всех;
   - проверка текста-заглушки `[message deleted]` у получателя.

5. `scenario_admin_actions`
   - регистрация администратора и пользователя;
   - блокировка/разблокировка пользователя;
   - сброс пароля (hash) пользователю;
   - проверка аутентификации с новым hash.

6. `scenario_persistence_relogin`
   - регистрация и логин пользователя;
   - создание нового экземпляра `ChatClient` с тем же username;
   - повторный логин за счет локально сохраненной key-pair.
